# 💬 FAQ-автоответчик для бизнеса

**Бот первой линии: отвечает на частые вопросы и собирает заявки 24/7.**

## Возможности

| | Функция | Описание |
|---|---|---|
| 📋 | Меню кнопками | Услуги / Цены / Контакты / Оставить заявку |
| 💬 | FAQ по ключевым словам | доставка, оплата, гарантия, сроки, скидки… |
| 📝 | Сбор заявок | имя → телефон (кнопка «отправить номер») → задача |
| 🔔 | Уведомление владельцу | готовая карточка заявки прилетает в ЛС |
| 🌙 | Нерабочее время | авто-приписка «ответим в рабочие часы» |

> Весь текст бизнеса — в `content.py`. Клиент меняет услуги, цены и ответы
> **без единой строчки кода**.

## Запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=ваш_токен ADMIN_CHAT_ID=ваш_id python bot.py
```

`ADMIN_CHAT_ID` — ваш числовой Telegram-id (узнать у [@userinfobot](https://t.me/userinfobot)),
туда падают заявки.

## Под заказ

Подключение к Google-таблице/CRM (amoCRM, Битрикс24), оплата прямо в боте,
рассылки по базе, несколько менеджеров. Настрою под ваш бизнес.
