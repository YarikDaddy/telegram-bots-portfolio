# 💰 Парсер цен

**Telegram-бот следит за ценой товара и пишет, когда она изменилась.**

## Возможности

| | Действие | Что делает |
|---|---|---|
| 🔗 | прислать ссылку | бот **сам находит цену** — CSS-селектор не нужен |
| 🔔 | автопроверка | каждые N минут; пишет «📈 выросла / 📉 упала» |
| 📋 | `/list` | что отслеживается и текущие цены |
| 🛑 | `/stop` | удалить отслеживание кнопкой |

Цена ищется в 4 слоя: **JSON-LD** (schema.org) → **meta-теги** → элементы с
классом `*price*` → регэксп по тексту. Понимает `₽ $ € £ грн`.

## Запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=ваш_токен CHECK_EVERY_MIN=30 python bot.py
```

## Ограничения (честно)

Работает на «лёгких» магазинах (Shopify, нишевые и западные шопы). Крупные
маркетплейсы (Ozon/WB/DNS) отдают цену скриптом или блокируют автозапросы —
для них нужен headless-браузер и прокси (делается отдельно, дороже).

## Под заказ

Конкретный магазин, отслеживание наличия/размеров, порог «дешевле X — купить»,
выгрузка истории цен в таблицу. Пишите — подгоню под вашу задачу.
