**Онлайн-запись в пару тапов + напоминания клиентам. Меньше неявок, меньше переписки.**

## Возможности

| | Функция | Описание |
|---|---|---|
| 📅 | Запись в пару тапов | услуга → день → свободное время → имя → телефон |
| 🟢 | Только свободные слоты | занятое время и прошедшие часы не показываются |
| 📋 | Мои записи | клиент сам смотрит и отменяет запись |
| 🔔 | Напоминания | автоматически за день и за 2 часа до визита |
| 👤 | Уведомление владельцу | каждая запись и отмена прилетает в ЛС |
| 💾 | Не теряет данные | всё хранится в `bookings.json`, переживает перезапуск |

> Услуги, цены, длительность, рабочие часы и адрес — в `content.py`.
> Клиент меняет всё **без единой строчки кода**.

## Запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=ваш_токен ADMIN_CHAT_ID=ваш_id python bot.py
```

`ADMIN_CHAT_ID` — ваш числовой Telegram-id (узнать у [@userinfobot](https://t.me/userinfobot)),
туда падают новые записи и отмены.

## Под заказ

Выбор мастера, привязка к Google-таблице, депозит/предоплата прямо в боте,
